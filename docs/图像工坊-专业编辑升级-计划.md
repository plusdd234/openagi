# 图像工坊 · 专业编辑升级计划

- 状态：已生效（D1–D4、界面专业化 U1–U4、双编辑器 V1–V4 已完成，`tools/probe-imglab.js` 全绿）
- 日期：2026-11-16（2026-11-17 增补 U4 移动对齐、V1–V4 位图/矢量双编辑器与布尔轮廓化）
- 适用范围：`apps/imglab` 与 `js/ps-*.js`、`css/13-imagelab.css`、`tools/probe-imglab.js`

## 1. 调研：专业 PS 的操作方式

从 Photoshop 的公开交互模型提炼出与本项目直接相关的六条：

1. **非破坏性优先**：图层蒙版、调整层、智能对象把「改什么」与「改多少」分开。原图始终保留，随时可回退。
2. **图层是唯一的编辑对象**：画笔、滤镜、变换都作用于当前图层；蒙版与内容是两个可切换的编辑目标（缩略图选中态）。
3. **锁定语义分层**：透明像素 / 图像像素 / 位置 / 全部是四种不同的限制，不是一颗「锁」。
4. **选择是编辑的边界**：选区、蒙版、通道都在限制「改动落在哪里」。
5. **导航不打断编辑**：空格拖拽平移、滚轮缩放、抓手 / 缩放工具是同级能力，不靠菜单。
6. **反馈闭环**：直方图、导航器、图层缩略图、状态栏在同一视线范围内，改完立刻能看到结果。

编辑优化的核心不是加特效，而是：**减少不可逆操作、减少工具切换、减少视线跳转**。

## 2. 现状盘点（代码事实）

已具备：瓦片化像素存储、mip、图层混合模式/不透明度/可见性、调整层、矢量形状层、选区（矩形/椭圆/套索/魔棒/反选/羽化）、历史事务、工程序列化、滤镜、钢笔。

缺口：

| 缺口 | 现状 | 后果 |
|---|---|---|
| 图层蒙版 | 完全没有 | 只能擦除/撤销，无法局部隐藏后反悔 |
| 图层锁定 | 四个按钮只切换 CSS 高亮 | 界面在骗人，属于技术债 |
| 抓手 / 缩放 | 工具箱里是占位控件 | 只能靠空格/滚轮，工具切换路径不完整 |
| 直方图 | 信息面板只有文字 | 调色缺少量化反馈 |
| 选择组合（加/减/交） | 只能整体替换 | 复杂选区要一次画完 |
| 自由变换 / 图层组 / 调整层蒙版 | 无 | 大工程暂时用不上 |

## 4. 本轮实现方案

### 4.1 蒙版数据模型

- `layer.mask = { enabled, tiles: Map, width, height, version }`，仅像素图层可创建。
- 蒙版与图层共用瓦片网格；瓦片是 RGBA 画布，**alpha 表示「隐藏量」**（0 可见，1 隐藏），缺省瓦片视为完全可见。
- 合成：先把图层内容画进离屏缓冲，再用蒙版以 `destination-in` 裁剪，最后按不透明度/混合模式落到主画布。
- 蒙版不烘焙进 mip；有蒙版时不走 mip 快路径，保证边缘正确。
- 历史：蒙版瓦片与像素瓦片共用事务，记录键加 `M` 前缀，撤销/重做逐瓦片还原。
- 工程：蒙版按整层灰度 PNG 存 `mask.png`，加载时按瓦片反解 alpha；工程版本升到 2，兼容 v1。

### 4.2 锁定语义

- `layer.locks = { transparent, image, position, all }`，取代旧的 `locked` 布尔值。
- 旧工程 `locked:true` 迁移为 `locks.position`；背景层默认位置锁定。
- 拦截点：移动（position/all）、画笔/橡皮/渐变/填充/文字/滤镜（image/all）、蒙版绘制（image/all）。
- 透明像素锁：笔画/填充/渐变结束后把 alpha 通道还原为落笔前，颜色仍可改。

### 4.3 导航与反馈

- 工具表新增 `hand`（H）、`zoom`（Z），删除对应占位项；抓手拖拽平移，缩放单击放大、Alt 单击缩小。
- 导航器下方加 RGB 直方图，数据取自导航缩略图，编辑后随面板刷新。

### 4.4 交互细节

- 图层行：内容缩略图在前，蒙版缩略图在后；点蒙版缩略图进入蒙版编辑，点内容缩略图回到像素。
- `Alt + 点击蒙版缩略图`：停用/启用蒙版。
- 图层面板工具条与右键菜单：添加 / 停用 / 应用 / 删除蒙版。
- 蒙版编辑时画笔用前景色灰度决定隐藏/显示：深色隐藏，浅色恢复；橡皮擦恢复。

### 4.5 界面专业化（第二轮）

- **U1 通道面板**：RGB 复合 + 红 / 绿 / 蓝四行，带真实缩略图（取自导航缩略图，按通道铺灰度）。
  单击任一行进入单通道预览：画布黑底、通道映射为灰度；只影响屏幕显示，不改图层像素。
  `Ctrl+2/3/4/5` 对应 RGB / 红 / 绿 / 蓝，状态栏颜色模式芯片同步显示「红 通道 · 8 位」。
- **U2 路径面板**：按矢量图层分组列出矩形 / 椭圆 / 直线 / 自由路径，显示尺寸与填充 / 描边状态。
  单击形状会切换活动图层并在画布上高亮（基础形状虚线描边，自由路径显示锚点）；图层眼睛可直接显隐。
- **U3 菜单与状态栏**：菜单已展开时，鼠标横向划过其他标题直接切换；再次单击同一标题收起。
  状态栏新增颜色模式芯片，单通道预览时以强调色提示，避免误以为仍在 RGB 复合视图。
- **U4 移动对齐辅助**：移动工具拖动图层时，把图层内容的左/中/右、上/中/下吸附到文档边缘/中心
  与其他可见图层的对应边，阈值按 6 屏幕像素换算，缩放时手感一致；命中时画布显示洋红参考线。
  `Ctrl` 临时关闭吸附，`Shift` 约束水平/垂直；选项栏与「视图 → 智能参考线（对齐）」都可开关。
  像素层包围盒按实际 alpha 计算并按图层版本缓存，连续拖动不重复扫描像素。

### 4.6 双编辑器与矢量布尔（第三轮）

- **V1 模式切换**：右上角「位图 / 矢量」分段控件，快捷键 `F2` / `F3`；模式写入工作区状态，重开保持。
  位图模式只显示像素工具（画笔、橡皮、渐变、油漆桶、选区、裁剪、文字等），矢量模式只显示钢笔、形状、路径选择，
  工具箱、选项栏、菜单（新增「矢量」菜单）与右侧默认标签（矢量 → 路径）同步切换。
- **V2 矢量形状组合**：形状支持 `op = add | subtract | intersect | exclude`，按数组顺序复合：
  `source-over / destination-out / destination-in / xor`。普通形状仍走直接绘制，只有出现非 `add` 才进离屏缓冲，
  避免给所有矢量图层增加开销；第一条路径即使标记为减去也按合并绘制，符合 PS 行为。
  矢量模式下形状/钢笔默认「合成到当前形状层」，让布尔运算能直接作用于同层多条路径；追加与改 op 都可撤销。
- **V3 快捷键忠实还原（只做有真实能力的项）**：
  `Ctrl+Shift+N` 新建图层、`D` 复位黑白、`X` 交换前景/背景、`Shift+M` 矩形/椭圆选区互换、
  `Shift+[` / `Shift+]` 画笔硬度、数字键设定画笔不透明度（连续两位数字如 4→5 = 45%，0 = 100%）、
  移动工具下数字键改当前图层不透明度、`Alt+Backspace` 前景色填充、`Ctrl+Backspace` 背景色填充、
  画笔下 `Alt` 临时吸管、`Shift+Tab` 只收起右侧面板、`Alt+Backspace` 与路径删除的优先级按 PS 处理。
  未实现的 `Ctrl+T`、图层组、选区加/减/交等不伪造快捷键，保留在第 3 节下一轮。

### 4.7 布尔轮廓化（V4，写入锚点）

- **目标**：把「视觉复合」推进为「真正写回路径锚点」的几何结果，用完还能继续编辑节点，而不是一张位图。
- **入口**：矢量菜单「轮廓化布尔结果（写入锚点）」→ `doAction('outlineShapes')` → `PS.outlineShapeLayer(doc, layer)`；整体可撤销。
- **数据模型**：`path` 形状新增 `subpaths = [{ pts, closed }]`；`shapePath` / `shapeBounds` / `cloneShape` 一并支持，
  填充走 `ctx.fill('evenodd')`，因此外轮廓 + 内部孔洞能正确挖空。
- **算法**：按图层复合包围盒建超采样画布（面积 > 3MP 时 S=1，否则 S=2）→ 用既有 `paintShapeWithOp` 逐条复合 →
  Marching Squares 提取 alpha 等值线（0.5 等值面，边线性插值，鞍点 5/10 用中心均值消歧）→
  端点量化串环 → 迭代 RDP 简化（`0.45` 文档像素）→ 过滤微小环并按面积排序。
- **结果**：一条 `op:'add'` 的 `path` 形状，保留顶层填充 / 描边，带孔洞；撤销恢复原布尔路径数组与图层版本。
- **边界**：只处理含非 `add` 运算且至少两条路径的形状层；纯 `add` 图层无需轮廓化（本来就是真实锚点）。

## 5. 验收路径

1. `node tools/probe-imglab.js --json`：新增蒙版、锁定、抓手/缩放、直方图断言全绿。
2. `node tools/test-headless.js imglab`：静态守卫 + 探针串行通过。
3. 手工回归：新建 → 画笔 → 加蒙版 → 蒙版上擦 → 停用/启用 → 应用 → 撤销/重做 → 保存工程 → 重新打开，像素与蒙版结果一致。
4. 回归项：向下合并、拼合、复制图层、裁剪、导出不因蒙版/锁定退化。
5. 界面专业化：通道面板四行与单通道切换、`Ctrl+2` 回 RGB、路径面板列出与选中、菜单悬停切换均由探针覆盖。
6. 移动对齐：吸附文档中心、吸附其他图层边缘、`Ctrl` 临时关闭、`Shift` 约束方向，均有探针断言与参考线状态检查。
7. 双编辑器：`F2/F3` 与右上角控件切换模式，工具箱与右侧默认标签同步过滤；探针覆盖位图 ↔ 矢量往返。
8. 矢量布尔：同一形状层四条路径的减去 / 相交 / 排除逐像素断言（重叠区挖空、只保留重叠、只保留不重叠），
   首条路径强制合并、形状选项栏四种布尔按钮与 `TEST.appendShape` 均有探针覆盖。
9. PS 快捷键：`X/D` 颜色、`Shift+M` 选区类型、`Ctrl+Shift+N` 新建图层、数字键不透明度、`Shift+[` 硬度、
   移动工具数字键图层不透明度、`Alt+Backspace` 填充、`F2/F3` 模式，均有探针断言。
10. 布尔轮廓化：外层矩形减去内部矩形 → `outlineShapes()` 后只剩一条 `path`，`subpaths = 2`（外轮廓 4 点 + 孔洞 4 点）；
    渲染断言外轮廓 alpha=255、孔洞 alpha=0；`undo()` 恢复两条原始布尔路径。

## 6. 明确不做（本轮）

- 选区加/减/交、自由变换、图层组、剪贴蒙版、调整层蒙版、标尺参考线。
- 轮廓化只做折线近似（RDP），暂不做贝塞尔曲线拟合；结果仍是可继续编辑的锚点，需要曲线时在矢量模式手工调整。
- 以上方向保留在本文件第 3 节，下一轮按 D5 → D6 → D7 顺序推进；届时先补数据结构设计再动代码。
