## 1. AI 爬虫搜索

### 1.1 能做什么

OpenAGI 内置了一个**自研 AI 爬虫搜索**，和常规 AI 搜索最大的区别是**不受"十几篇文章"上限**：

- 一个问题 → 抓**上百条结果**（网页/贴吧/聊天记录/新闻，GitHub 单开一条通道做项目识别）
- 对每条结果做**关键词提炼 + 词表整合**，只把低成本摘要送进上下文
- 再**按线索挑少数几条深读**，抽出新线索 → 回到第一步做「深度搜索」

UP 原话：「一般的 AI 搜索都会给你有个十几篇的文章限制，而我这个会直接进行上百篇幅的搜索，之后通过关键词提炼，把文章中出现的词语进行整合……然后再选择性地精读每个网址。」

### 1.2 拆成三段算法（不用猜，他视频里说了）

```
① 广搜（breadth）：一个问题 → 抓上百条结果
② 粗读（skim）：对每条做关键词提炼 → 得到"这条大概讲什么"的低成本描述
③ 精读（deep）：按线索挑少数几条深读 → 从精读内容再抽线索 → 回到 ①
```

**关键点**：上限不是"文章数"，而是**粗读成本**——第②步只用词表不进全文，所以敢抓上百篇。

### 1.3 用法建议

1. **调研外部工具/仓库**时，别一上来全文抓（贵且容易读到一堵墙）。先广搜多 query 合并，看 sources 标题 + 摘要筛。
2. 筛选后**只对 2–4 个 URL 拉全文**，且带明确问题。
3. GitHub 类目标单独一轮，关键词带 `site:github.com` 或"工具名 + star"——这条通道 UP 专门优化过。
4. UP 自己两次强调「还在开发中，很多不太完善」——**当"扩召回"用，结论仍要自己验证**。

## 2. 自研建模工具

### 2.1 为什么不用 Maya / Blender

UP 原话：「每次都要启动 Maya 非常不方便，所以我就想能不能自己用 AI 做一个自己的建模工具，直接放到自己的工具集里。」它**不通过文件管理，而是直接通过模型库**，方便对接工作流。

### 2.2 主要功能

| 功能 | 说明 |
|---|---|
| **模型库而非文件** | 资产是"库里的条目"，不是磁盘上的 `.blend` 文件 |
| **UV 编辑器 + 分组** | 支持岛级 UV 操作，这是后面 UV 岛系统的基础 |
| **贴图绘制** | 直接吸取模型上的颜色，在贴图上面修改（类似 Blender 纹理绘制 + 吸管） |
| **自写挤出工具** | 独立坐标轴：拉取轴方向调挤出距离；拖曳轴心圆球左右滑动调收缩/扩张 |
| **合并挤出 / 分离挤出** | 对应 Blender `Alt+E` 的两个选项 |
| **Ctrl+Z 全局撤回** | 绘画和建模统一 undo 栈 |

### 2.3 UV 岛系统（本视频真正的增量）

UP 原话：「传统建模软件有点线面体系统，我这里还多了一个 **UV 导（岛）系统**。」因为 AI 自动 UV 之后，模型实际上就已经完成了分块——每个岛天然就是一个部件。

> **最值钱的一条**：「传统我要拆分一个头发或者部件，都要花上 15–20 分钟，而且拆出来的很容易弄碎；但 UV 岛具有天然的一贯性，**以前 15 分钟要干的事情，现在不到一分钟就能搞定**。」拆出来后想要改贴图、或重新 AI 渲染贴图，都非常方便。

用法：**AI 自动展开 UV → 按岛选（或按岛归并成部件）→ 分离**。

### 2.4 边界

- UP 自己强调「依旧在开发中，功能还不太完善」（爬虫一次、建模工具一次）。
- 它是 **Electron + 原生 JS** 的网页式建模器，**不是**替代 Maya/Blender 的成品。
- 仓库审计文档自己写着：修改器栈只有空壳求值器、挤出直接烘焙进基础网格，副作用「挤出后全身贴图错乱」——**建模/挤出那部分是半成品，UV 岛那部分是全的**。

## 3. 视图工坊（原"多视图工具"改名）

### 3.1 能做什么

「它可以根据模型生成**结构和轮廓**的参考，里面甚至有一套**渲染管线**，包括完整的**描边效果**、**后处理**、**UV 岛模型的线框**、**多边形线框**，都可以自己选择性开启。」可以像**图层**一样排布顺序、隐藏和显示。

### 3.2 解决什么问题（整条视频的技术核心）

一句话：**把"参考图"和"模型的屏幕投影"强制到同一坐标系**。

- 结构参考（灰模/白模轮廓）+ UV 岛线框 + 多边形线框 → 叠成一张"这张图哪个像素属于哪块面"的图。
- 图像模型拿这张图当参考，就只能往它指的位置画 → **幻觉被物理性地压掉**。
- UP：「可以看到我每一次升图，基本上是 100% 能够对齐的。这对自动化工作流来说非常重要。」

### 3.3 为什么像素对齐值钱

1. **提高出图效果**：完全不修改贴图、直接用 Tripo 进行贴图的效果——像素对齐能很大程度减缓幻觉。
2. **给"还有幻觉"留了后手**：最难搞的眼睛问题——参考图能跟模型完全对上，就可以**直接用参考图投射到对应的 UV 岛上**，画一个遮罩层，把 UV 岛回轰到模型表面。

### 3.4 实际操作顺序

```
[调研] AI 爬虫：广搜 → 粗读上百 → 精读少数 → 深度搜索
   ↓ 定参考 / 定工具
[生成] Tripo 出网格
   ↓
[分件] AI 自动 UV → UV 岛系统选岛 → 分离头发/部件（15–20 min → <1 min）
   ↓
[参考图] 视图工坊：结构+轮廓+UV 岛线框，图层式开关 → 渲一张像素对齐图
   ↓
[贴图] 图像模型以对齐图为参考出贴图
```
