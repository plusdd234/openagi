## 第一部分 · 120 形态键的表情管线（BV1vqyRzrEMs）

### 1.1 做了什么

「整个制作流程**我只用到了 Tripo**，没有用什么特别厉害的 AI 工具和软件，基本上**全靠 DeepSeek 写的**，项目已开源。」更新点是**头部生成**：支持 **120 个形态键**，配一套**捏脸系统** + **纹理图层系统**。

### 1.2 形态键重定向：比例混合 + 顶点位置偏移

- 「做了一个**拥有 120 个形态键的映射头模**，以及配套的**捏脸系统**。」
- 「此捏脸系统采用了一种独创的**比例混合、顶点位置偏移技术**，可以根据**五官分布动态适配**形态键的变化，来**避免穿模**。」
- 「把**绝对的位置偏移转化为比例偏移**，实现**形态键的重定向**。」

**关键认知**：形态键本身是**绝对顶点偏移**，一旦套到"比例不同的脸"上就穿模/错位。改成**比例偏移**（相对五官分布），等于给形态键做了**重定向（retarget）**——**一个头模的 120 个键可以套到所有模型上**。

- 「首先你不管是人还是 AI，**制作 120 个形态键都不太现实**，所以把头模这个最复杂的部分**参数化**了——**AI 只要照着图片不断调节参数**，就可以达到一个比较好的效果。」

### 1.3 纹理图层系统（不拆件 = 拆件效果）

- 「对于传统模型来说，它**只有一张贴图**；但在这里我拓展了一套**纹理图层系统**：像 **PS 文件**一样，每一个模型上的纹理是**多个图层和遮罩叠加**起来的。」
- 「这意味着我可以让**多个模型共用一张纹理图**，然后让 AI 对每一个部位**重新生成**，最后通过**纹理混合图层**加上用这个部位的 **UV 遮罩**叠加起来，从而实现一种**不拆件就能实现跟拆件相同的贴图效果**，不会受到遮挡影响。」

> **拆件的目的是"让生成时只看见一个部位"**；他用 **UV 遮罩 + 图层**在**纹理空间**上达到同样效果，于是**不用真的动拓扑**。代价：图层叠加的最后一步仍是"每个部位各生成一张"，边界处一样可能串色。

### 1.4 专用建模软件里的闭环（自动化顺序）

```
1. 在建模软件里把部位「分为一个组」（= 选 UV 岛）
2. 自动渲染「轮廓图 / 结构参考图」
3. 图 → 着色后的模型效果图 → 作为「生成纹理参考」
4. 自动上传 Tripo 生成纹理 → 自动下载
5. 按该部位的 UV 生成遮罩 → 叠加到「纹理混合图层系统」
```

- 「这样就省去了**不断的拆解模型部位、然后导出**的过程。」
- 「为什么我这个建模软件里的人物**可以动**？只要在建模软件的基础上加一套**运行时渲染系统**就行了——相当于有一个**每帧调用**的渲染程序，不断驱动他的**表情、眨眼、还有看向我**。」
- 「我的**头发和身体是共用一张 2K 贴图**的。为了不污染其他的区域，它会根据我**当前选中的对象的 UV 分布自动生成遮罩**，然后叠加到纹理混合系统。衣服也是这样形成的。」
- 「（分件麻烦吗？）其实不麻烦，因为我这个模型在**导入的时候就已经 AI 自动展过 UV** 了，而我自己这个建模系统可以**继续按照 UV 岛选取**，所以分件过程是非常简单的。像**皮肤、手套这些都是天然的独立 UV 区域**。」

### 1.5 边界

- 「这部分功能是我**昨天晚上刚弄出来的**，所以很多 bug 而且还不完善。」
- 「看过我以前视频的小伙伴就知道我以前有做过**节点图和 AI 抽卡**，我把这个连接到那个系统下面，**理论上**就可以 AI 来抽卡。这部分功能可能会在**未来一到两个月之内**更新。」
- 「后面也许我会研究除了头部以外的更多部位，比如**身体、头发这种参数化的模型**，到时候做成**组件**集成在软件中进行调整。」

## 第二部分 · AI 动画生成系统（BV1Fjpy6SEmF）四层结构

### 2.1 定位

- 「所谓**全能**就是：**无需依赖任何模板和动画素材库**，只需要有一个大模型，甚至是 **DeepSeek** 也能做。」
- 「这次最大的更新是增加了**叠加动画层混合系统**：在原本 AI 生成**基础动作**的基础上，又形成了若干**微小的叠加动画**。这些叠加动画不仅能够**消除 AI 动作的停顿感和机械感**、增加更多的姿态细节，还可以通过**后期人为调整曲线**得到自己想要的效果。」
- 「该动画系统由**多个垂直运作的子系统**构成。」

### 2.2 四层子系统

#### 第一层 · 细节系统：不截图，传骨骼 JSON

- 「传统 AI 制作动画需要**不断截图**，而为了专门制作动画，我弄了一个**骨骼打包系统**：可以根据当前视角，把**骨骼位置和深度打包成一个 JSON 文件**回传给 AI 进行观察，这样才能得到**精确的无遮挡的骨骼**。」
- **好处有三**：① 没有图像分析，大幅削减时间；② 细节省 token；③ 截图仅能获取模糊位置且受遮挡影响，而骨骼位置 + 深度可以获取**精确位置**。

#### 第二层 · 虚拟骨骼系统：补边界与关键点

- 「在原始骨骼的基础下，对所有骨骼进行分类**标签**，提高数据包的**可读性**。」
- 「其次就是自动追加**虚拟骨骼**，用于标记一些模型的**边界和关键点位**：比如这里的骨骼实际上**只到脚踝**，那么我就需要增加一根虚拟骨骼**一直拉到脚尖**，这样通过**纯骨骼分析**也能得到完整的运动状态。」
- 「**虚拟骨骼也可以用来标记关键点位**，比如**武器的尖端**，用于**检验穿模状态**。」

#### 第三层 · 设定系统：平面设计 + 带根运动

- 「首先把**骨骼的信息敲到平面上**，然后在平面上面**设计带根运动的运动动画**——这个将会作为**基础动画的验收标准**。」
- 「**基础动画保证运动（的）合理性**：比如**脚步落点**、比如**重心分配**。」

#### 第四层 · 叠加动画系统：相对旋转增量

- 「叠加动画记录的**不是骨骼的绝对位移，而是相对旋转增量**。因此可以通过**曲线幅度**控制这个增量的叠加程度，实现动画的**精致微调和细节复合**。」
- 「由于这个系统**没有依赖任何的动画库**，所以理论上**可以做任何骨骼的模型**：不管是人物、四足动物，或者是身上有装备的、或者头发、或者裙子这种复杂骨架，都可以按照此方式进行实践。」
- 「基础动画保证运动合理性（脚步落点、重心分配），而**叠加动画控制美术细节**：比如人物的**体态、性格以及各种微动作**。」

## 第三部分 · 贴图工具包（BV142n36AEdm）

### 3.1 用法

1. 「点开启动程序后，会进入这个界面；点击右上角这个**导入 OBJ**，它会把你导入的模型**自动烘焙成 2K 或 4K 的深度图**。」
2. 「做这一步的目的：当你根据原画生成模型之后，**模型实际生成的四视图，结构和体积会和原画有所不同**。如果你直接沿用原来的原画作为贴图参考，会导致**幻觉累积**——无处安放的贴图就会成为**噪声或者是混乱的图片**。」
3. 「所以就需要使用一些工具，根据**生成好的模型**，把**真实的四视图渲染成标准四视图参考**，然后再**结合原画**，让**nano banana 2**之类的模型对它进行**精准上色**。这样就能避免幻觉累积、提高贴图效果。」
4. 「同时你可以导出高质量的 **4K/2K 图片，然后叠加模型的深度**；而且它这个**线框是不会穿透的、有遮挡关系的**，能够**清晰表达结构和深度信息**。」
5. 「一般就是**开深度、背景透明化、线宽拉到最低**，这样你**一张图上就可以复合结构、遮罩、深度三种不同的信息**，就容易出比较高质量的图片。」
6. 「这个工具在**群文件**里面可以下到」（群 1108459704）。

### 3.2 为什么这条最实用

- **背景透明 + 最小线宽 + 深度叠加** = 一张图同时携带「结构 / 遮罩 / 深度」三种条件。
- **线框不穿透（有遮挡关系）** = 线框是"可见性正确的"，不会把背面线画到前面——这正好是"像素对齐"的前提。

## 结论与边界

### 该抄（按性价比）

1. **骨骼 JSON 替代截图**（动画验收）——省 token 且不受遮挡骗。
2. **虚拟骨标记关键点**（脚尖/武器尖端/裙摆末端）——用来做"纯骨骼穿模判定"。
3. **深度 + 线框 + 透明底三合一参考图**（贴图阶段）。
4. **纹理图层 + UV 遮罩**（不拆件达到拆件效果）。
5. **形态键比例重定向**（长期）——想走 morph 表情路线必须先有映射头模。

### 别当结论

- **形态键那条别立刻上**：他自己说"昨晚刚弄出来、很多 bug"。
- **"分件很简单"**：他的简单来自"导入时已自动展 UV + 能按 UV 岛选"。
- 他的工具都在**群文件**，不在 GitHub 仓库主链——**别假设仓库里有**。
