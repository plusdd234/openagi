## 视频里的叫法 ↔ App 注册名

视频是口语讲解，界面上实际显示的名字略有不同。对照表（仓库 `apps/manifest.js` 的注册名）：

| 视频里的叫法 | App 目录 | 界面注册名 |
|---|---|---|
| AI 爬虫搜索 / 深度搜索 | `apps/aisearch` | **智搜** |
| 多视图工具 → 视图工坊 | `apps/multiview` | **视图工坊** |
| 自研建模工具 | `apps/modeldesk` | **建模** |
| 模型库 / 模型商店 | `apps/gallery` / `apps/store` | 模型库 / 模型商店 |
| Tripo 桥 | `apps/tripostudio` | **Tripo 工坊** |
| 角色工坊 / 图像工坊 | `apps/chara` / `apps/imglab` | 角色工坊 / 图像工坊 |

## 一句话总纲

> **AI 生成是一个线性工作流，上游的错误会在下游不断累加放大。** 所以与其事后修，不如把每个环节的入口抠到极致——
> 参考图对齐、生成端控面、按部件拆分，都是在"入口"解决问题。OpenAGI 的工具链就是围绕这条思路搭的。
