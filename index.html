方式二 · API Key（3D 生成的兜底）
网页助手没连接时，「3D 生成」节点自动改走 Tripo 开放接口；填了 Key 就有这条退路。
获取 Key
3D 节点的取用顺序：网页助手已连接 → 走网页账号；未连接 → 走这里的 API Key。Tripo 不开放浏览器跨域，API 调用需在 设置 → 本地中转 中启用中转。
怎么用起来
两步：① 点上面的「打开登录页」，在弹出的浏览器里登录 Tripo 并进入生图页；② 状态显示「已连接」后，画布里的「Tripo 网页生图」（最多 3 张参考图）、「Tripo 网页生成模型 / 多视图」节点即可运行；「3D 生成」节点优先走网页账号，未连接时用下方 API Key。

助手启动：桌面模式（双击 start.bat 或安装版）下由主进程自动托管，无需手动操作；纯网页模式要先手动运行 node plugins/tripo/tripo-web.js --serve（需已 npm install，Edge 会自动打开）。桌面端把实际端口写进页面（?tripo=），这里显示的「助手地址」就是当前生效值。

它是怎么工作的
搜到的摘要会经本地中转 8787 转发（浏览器直连第三方网页必被跨域拦），请先在「本地中转」里启用并启动。免 Key 的 DuckDuckGo 抓的是网页版结果，可能被反爬页或网络挡掉；长期用建议自建 SearXNG（需开 format=json）或填 Tavily Key。
检索结果只进本轮对话的 system 提示，不进历史记录；回答里带 [序号] 的引用可以点到原文。
中转服务
灵算、Tripo 这类不开放跨域的服务商，请求改由本机 8787 转发。Key 仍只在本机，不会经过第三方。
双击项目里的 start.bat 一键启动（桌面模式下本地中转已由主进程托管），再点测试中转。也可手动运行 node plugins\relay\relay.js。

工作流编排、本地生图（ComfyUI）、3D 生成与多视图、对话内生图、媒体播放——都在一台机器上跑，模型可以全本地。
开源（MIT）。所有 Key、工作流、资产都存在本机浏览器存储与用户数据目录里，没有账号也能用完整功能。
数据与隐私
API Key 存 localStorage，仅在请求你配置的服务商时带上，不经任何中间服务器（除非你自己开了中转）。
生成的工作流、图片、3D 资产存在浏览器 IndexedDB 与桌面端用户数据目录；卸载应用不会自动删除它们，需要手动清。
「清空全部 Key」只清 Key，不动工作流和资产。
